# LTEE variant calling

Variant calling on three E. coli samples from the Long-Term Evolution Experiment

Author: Yuqi Lei

## Reproduce the results

You need [Pixi](https://pixi.prefix.dev/latest/) and an internet connection.
Then, from this folder:

```bash
pixi install          # builds the exact environment recorded in pixi.lock
pixi run reproduce    # downloads the raw data and rebuilds every result
```

`pixi run reproduce` must work on a fresh clone of this repository. A GitHub
Action (`.github/workflows/reproduce.yml`) checks that on every push.

Each folder has its own `README.md` with more detail.

## Data

Raw reads: a subset (175,000 read pairs per sample) of three *E. coli* clones
from the Long-Term Evolution Experiment (population Ara-3, generations 5,000,
15,000 and 50,000), prepared by Data Carpentry:
<https://doi.org/10.6084/m9.figshare.7726454> (file `sub.tar.gz`, CC0).
Reference genome: *E. coli* B str. REL606, GenBank CP000819.1 (NCBI).
Details, sample sheet and checksums are in `metadata/`.

## Data availability

Raw reads are in NCBI BioProject PRJNA295606 (runs SRR2589044, SRR2584863

*E. coli* B str. REL606, GenBank CP000819.1 (NCBI). This repository's code

from the recorded sources with the project workflow.

## Container

The pipeline's software also runs in a Docker image built from `pixi.lock`
(`containers/Dockerfile`), so a container and a laptop run exactly the same
packages. Build it from this folder:

```bash
docker build --platform linux/amd64 -f containers/Dockerfile \
  --build-arg ENV_NAME=pipeline -t ltee-project:0.1.0 .
```

Run the pipeline in it, with the project mounted at `/work`:

```bash
docker run --rm -v "$PWD":/work -w /work ltee-project:0.1.0 \
  bash scripts/run_variant_calling.sh
```

On every push, GitHub builds this image, runs the variant calling in it and
checks that it gives the same counts as a laptop (10, 25 and 775 variants):
`.github/workflows/container.yml`. The summary of each Container run gives
the image ID, which identifies the exact image behind that run's results.
